# GraphX Packages

Official first-party ecosystem packages for GraphX.

The GraphX engine lives separately in [GraphX 2](https://github.com/roipeker/graphx2). Packages here consume GraphX through its public API and may evolve together in this Pub workspace.

## Packages

- `graphx_paths` — retained geometric paths and allocation-aware spatial sampling.
- `graphx_motion` — allocation-aware tweens, retained timelines, keyframes, stagger, and motion physics.
- `graphx_atlas` — GraphX atlas format decoding helpers; build-time packing and Dart ID generation use the canonical atlas tooling.
- `graphx_particles` — packed retained particle emitters, fields, constraints, trails, and secondary effects.
- `graphx_arcade` — small deterministic fixed-step 2D arcade physics for game workloads.
